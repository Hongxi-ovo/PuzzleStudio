使用说明
01 · 摆场点击场地格选卡；点击牌堆查看区域内卡片。也可以从卡库拖入，或拖动场上的卡片。
02 · 卡片状态选中卡片，在右侧调整表示形式、数值、属性、种族、抗性和对象；也可从卡片提取赋予效果。切换到 Lua 页签，可以给它添加独立脚本效果。
04 · 规则场地上方可切换 2014 / 2017 / 2020 规则。灵摆区及共享额外区会按规则变化，冲突会阻止导出。
05 · 保存和导出工程 JSON 保留全部编辑状态；Lua 用于运行。浏览器会自动保存最近工程。
快捷键Ctrl+Z 撤销 · Ctrl+Shift+Z 重做 · Ctrl+S 保存 · / 搜索 · Delete 删除选中卡片。
完整卡图优先读取本地高清缓存；下载期间使用内置图。Lua 片段在导出后由游戏核心执行。
